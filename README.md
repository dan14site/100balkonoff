# 100balkonoff — сайт-визитка

Статический сайт для GitHub Pages.

## Загрузка в GitHub

В репозитории должны находиться `index.html`, `style.css`, `script.js`, `logo.svg` и папка `images` с фотографиями. `index.html` должен лежать в корне репозитория.

## Игра

Встроенная мини-игра адаптивна по размеру экрана, бобёр анимирует ногами и лапами, держит молоток, бежит к балкону, прыгает через компактные брёвна, постепенно ускоряется и имеет отдельное окно финиша/проигрыша с кнопкой «Начать с начала».
