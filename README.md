# 100balkonoff — сайт-визитка

Статический сайт для GitHub Pages.

## Загрузка в GitHub

В репозитории должны находиться `index.html`, `style.css`, `script.js`, `logo.svg` и папка `images` с фотографиями. `index.html` должен лежать в корне репозитория.

## Игра

Мини-игра расположена внизу сайта, сразу после блока с телефонами.

Бесконечный раннер: бобёр бежит по лесу без финиша, как динозаврик на странице Google Chrome.
Скорость постепенно растёт, а фон меняется по циклу день → закат → ночь → рассвет
(днём светит солнце, ночью — луна со звёздами и падающими звёздами).

Управление:

- `Пробел`, `↑`, `W` или тап по игровому полю — прыжок;
- второе нажатие в воздухе — второй прыжок (с сальто), помогает перепрыгнуть высокое бревно;
- `P` или `Esc` — пауза, `M` — включить/выключить звук.

Препятствия: тонкое бревно, толстое бревно и ворона. Ворона летит на уровне головы —
под ней нужно **пробежать**, а не прыгать. Игра заканчивается после столкновения,
результат сохраняется как рекорд в браузере.
