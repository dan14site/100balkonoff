# 100balkonoff — сайт-визитка

Статический сайт для GitHub Pages.

## Загрузка в GitHub

В репозитории должны находиться `index.html`, `style.css`, `script.js`, `logo.svg` и папка `images` с фотографиями. `index.html` должен лежать в корне репозитория.

## Игра

Мини-игра расположена внизу сайта, сразу после блока с телефонами. Бобёр бежит к балкону, а не к стройке. Управление: пробел, стрелка вверх или тап по игровому полю. Есть два прыжка подряд: второй можно сделать в воздухе, чтобы перепрыгивать высокие брёвна. Препятствия идут с безопасным расстоянием, игра продолжается до балкона, скорость постепенно растёт, а после столкновения показывается отдельное окно с кнопкой «Начать с начала».
