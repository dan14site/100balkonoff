# 100balkonoff — сайт

Статический сайт для GitHub Pages.

## Что внутри
- красно-белое оформление;
- фон с аккуратной натуральной вагонкой;
- новый талисман-бобр в красном комбинезоне с молотком;
- мини-игра: бобр перепрыгивает доски и бежит к балкону;
- после столкновения отдельное окно «Бобёр устал» и кнопка «Начать с начала» без наложения текста;
- после успешного забега бобр достигает балкона;
- портфолио с увеличением фотографий в полноэкранном режиме;
- каждая фотография дополнительно является прямой ссылкой на файл, поэтому она открывается даже при отключённом JavaScript;
- адаптивная верстка для телефона и компьютера.

## Как обновить сайт на GitHub Pages
1. Распакуйте архив.
2. В репозитории GitHub откройте **Add file → Upload files**.
3. Перетащите все файлы и папку `images` из распакованной папки в репозиторий.
4. Нажмите **Commit changes**.
5. GitHub Pages обновит сайт автоматически после публикации изменений.
